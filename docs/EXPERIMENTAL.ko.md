# 추가 확인 (실험)

기본 화면의 **추가 확인**에서 휴대폰의 신호·마이크·자기장·후면 카메라를 골라 살펴봅니다. 결과는 주변을 더 확인할 단서이며 기기 종류나 소유자를 판정하지 않습니다.

## 다섯 곳 신호 비교

1. 현재 목록에서 비교할 신호 하나를 고릅니다. 같은 이름의 신호는 **주소로 구분하기**에서 구별합니다.
2. **선택한 신호 받기**를 누릅니다. 이동 비교의 출발 세기를 기록하면 이후 **강해짐 / 약해짐 / 비슷함**을 표시합니다. 값이 없거나 오래되면 비교를 멈춥니다.
3. 교탁을 앞에 두고 **앞쪽 왼쪽 → 앞쪽 오른쪽 → 뒤쪽 오른쪽 → 뒤쪽 왼쪽 → 교탁 앞**을 차례로 기록합니다. 각 지점에서 휴대폰의 높이와 방향을 비슷하게 유지합니다.
4. 지점 측정을 시작한 뒤 실제로 새로 받은 패킷만 기록합니다. BLE는 여러 패킷과 2초 이상의 수집이 필요합니다. 와이파이는 새 검색 결과 1회부터 잠정 기록할 수 있고, 더 기다려 여러 결과를 모을 수도 있습니다. 한두 표본의 흔들림은 **아직 모름**으로 표시합니다.
5. 다섯 곳을 모두 모으면 중앙값과 흔들림으로 상대적으로 강했던 쪽을 넓게 표시합니다. 차이가 작거나 불안정하면 위치를 고르지 않습니다. 표본이 적으면 잠정 비교임을 표시합니다. 지점별 재측정과 전체 초기화를 지원합니다.

선택한 주소는 이름이나 그룹 대표가 바뀌어도 다른 주소로 이어 붙이지 않습니다. 와이파이는 기본 감시의 검색 주기를 이용하며, 별도로 받을 때도 30초 간격으로만 요청합니다. 시스템 제한 때문에 더 오래 걸릴 수 있습니다. 막대나 색칠은 미터·좌석·이동 거리의 백분율이 아닙니다.

## 작은 소리 변화

**마이크 시작**을 누를 때만 녹음 권한을 요청합니다. 실제 내장 마이크 경로를 확인하고, 지원되는 표본 속도로 짧은 PCM 블록을 분석합니다. 비가공 입력이 지원되면 사용하고, 아니면 음성 인식용 입력을 사용합니다.

- 3초의 안정된 기준 소리를 모은 뒤 낮은 대역(80–1,500 Hz)과 높은 대역(18–21 kHz)의 상대 에너지 변화를 비교합니다.
- Hann 창과 Apache Commons Math FFT로 최근 시간–주파수 그림을 표시합니다.
- 수초 동안의 진폭 포락선에서 반복되는 상승 구간을 살펴봅니다. 일정한 소리, 한 번의 변화, 단조롭게 커지는 소리를 반복으로 세지 않습니다.
- 실제 표본 속도와 휴대폰이 보고한 18–21 kHz 지원 여부를 따로 표시합니다. 표본 속도가 높다는 이유만으로 마이크의 고주파 응답을 보장하지 않습니다.
- 무음·과도한 입력·불완전한 읽기·차단된 입력·외부 또는 확인되지 않은 입력 경로는 정상적인 무변화 결과로 처리하지 않습니다.

휴대폰에 실제로 닿는 소리만 측정합니다. 선풍기·말소리·일반 전동기 소리도 변화를 만들 수 있습니다. 소리를 내보내거나 음성을 해석하지 않으며 원시 녹음을 저장하지 않습니다.

## 가까운 자기장 변화

**측정 시작**을 누른 뒤 휴대폰을 잠시 고정해 기준을 잡습니다. 움직이는 동안에는 비교를 잠시 멈추고, 멈춰 안정되면 같은 기준으로 다시 비교합니다. 자기장 크기의 변화와 최근 이력을 보여 줍니다.

센서가 없거나 시작에 실패한 경우를 안내합니다. 정확도 저하·포화·잘못된 값·오래된 값에는 기준을 다시 잡도록 안내합니다. 추가 확인 도구에서는 휴대폰 자체 진동을 끕니다. 자석·케이스·책상·구조물의 금속도 큰 변화를 만들며, 자기장 변화가 특정 이어폰이나 오디오 신호를 뜻하지는 않습니다.

## 빛 반사 찾기

**카메라 시작**을 누를 때만 카메라 권한을 요청합니다. 후면 카메라 미리보기 위에 주변보다 밝고 작은 반사 후보가 여러 프레임 동안 유지되는 위치를 표시합니다. 밝은 넓은 면, 큰 노출 변화와 움직임은 후보를 이어 붙이지 않습니다. 센서 좌표의 잘라낸 영역과 화면 회전을 미리보기 좌표에 맞춥니다.

휴대폰 불빛을 지원하면 직접 켜고 끌 수 있습니다. 빠르게 깜빡이지 않으며 외부 조명이나 깊이 센서를 요구하지 않습니다. 유리·단추·안경·금속도 반사하므로 표시된 곳을 가까이서 확인합니다. 사진이나 동영상을 저장하지 않습니다.

## 권한과 종료

마이크·카메라 권한을 거부해도 기본 무선 감시는 사용할 수 있습니다. 각 도구의 중지 버튼, 뒤로 가기, 화면 이탈은 해당 자원을 해제합니다. 화면으로 돌아왔다고 센서나 카메라를 자동으로 켜지 않습니다. 측정 결과와 짧은 분석 버퍼는 메모리에만 두며 자동 내보내기나 업로드를 하지 않습니다.

## 자동 검증

```sh
./gradlew testDebugUnitTest assembleDebug lintDebug
```

검증에는 기존 감시·스냅샷 읽기, 지점별 새 패킷과 캐시 구분, 단일 와이파이 결과의 잠정 상태, 평탄하거나 흔들리는 신호, 음향의 합성 톤·반복·클리핑·부분 읽기, 자기장의 이동 후 재개, 카메라의 작은 반사·행 및 픽셀 간격·잘림·회전 좌표, 비동기 종료와 권한 실패, 큰 글꼴의 화면 이동이 포함됩니다.
